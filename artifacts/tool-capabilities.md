# Tool Capabilities

## All Tools
- **Bing Search**: Searches the web for up-to-date information.
- **GitHub Read**: Retrieves repository data, including issues, PRs, files, and metadata.
- **GitHub Write**: Manages GitHub repository data, such as creating branches and updating files.
- **Lexical Code Search**: Finds code with exact word matches or patterns.
- **Semantic Code Search**: Searches code based on conceptual context.
- **GitHub Support Search**: Answers questions about GitHub features and support topics.
- **GitHub User Search**: Locates GitHub users based on their profile information.
- **GitHub User Self-Info**: Provides details about your GitHub profile.

## GitHub Write Capabilities

- Create a new branch.
- Create or update files in the repository.
- Merge pull requests.
- Push files to a repository.
- Update pull request branches.

### Supported Actions

1. **Create Branch:** Create a new branch from an existing branch.
2. **Create or Update File:** Add new files or update existing files with content.
3. **Merge Pull Request:** Merge an open pull request using different methods (merge, squash, rebase).
4. **Push Files:** Push multiple files to a specific branch.
5. **Update Pull Request Branch:** Update a pull request branch with the latest changes from the base branch.
